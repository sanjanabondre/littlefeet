# 👣 LittleFeet – Kids Footwear E-Commerce Website

**LittleFeet** is a modern kids' footwear e-commerce website built using React.js and Tailwind CSS.

The project also includes a **blockchain-based payment system** using Solidity, Hardhat, Ethers.js, and MetaMask.

The blockchain component allows users to connect their MetaMask wallet and send an ETH payment through a Solidity smart contract.

---

## 📌 Project Overview

LittleFeet is designed as a colorful and child-friendly footwear shopping website.

The website provides:

- 🏠 Home page
- 👟 Kids footwear showcase
- 🛍️ Product sections
- 🗂️ Categories
- 💳 Blockchain-based payment functionality
- 👛 MetaMask wallet connection
- ⛓️ Solidity smart contract integration
- 🔗 Local blockchain testing using Hardhat

The project combines a **React frontend** with a **blockchain backend** for demonstrating decentralized payment functionality.

## 2. MetaMask Wallet Connection

Users can connect their MetaMask wallet to the website.

When the user clicks the **Wallet** button:

1. The website checks whether MetaMask is installed.
2. MetaMask asks the user to connect an account.
3. The connected wallet address is retrieved.
4. The address is displayed in shortened form.
